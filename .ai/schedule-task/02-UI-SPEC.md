# 일정관리 게시판 UI/UX 명세

## 1. 화면 구성

### 1.1 일정 목록
경로 예시:
`/schedule`

구성:
1. 페이지 제목: 일정관리
2. 검색 영역
3. 신규 일정 버튼
4. AG Grid
5. 페이지네이션
6. 선택 행 상세/수정

## 2. 검색 영역

| 항목 | 타입 | 기본값 |
|---|---|---|
| 검색어 | text | 빈 값 |
| 시작일 | date | - |
| 종료일 | date | - |
| 상태 | select | 전체 |
| 우선순위 | select | 전체 |
| 담당자 | select/search | 전체 |

검색 버튼과 초기화 버튼을 제공한다.

## 3. AG Grid
권장 컬럼:
- checkbox
- ID
- 제목
- 시작일시
- 종료일시
- 상태
- 우선순위
- 담당자
- 장소
- 등록자
- 등록일
- 수정일

컬럼 정렬/필터를 허용하되 실제 검색은 서버 조건과 일치시킨다.

## 4. 등록/수정 화면
필드:
- 제목 *
- 설명
- 시작일시 *
- 종료일시 *
- 상태 *
- 우선순위 *
- 담당자
- 장소
- 공개 여부
- 색상

버튼:
- 저장
- 취소

수정 화면:
- 수정
- 삭제
- 취소

## 5. UX 규칙
- 필수 입력 누락 시 필드별 메시지 표시.
- 종료일시가 시작일시보다 빠르면 즉시 오류 표시.
- 저장 중 버튼을 비활성화한다.
- API 오류는 사용자가 이해할 수 있는 메시지로 표시한다.
- 삭제는 반드시 확인 절차를 거친다.
- 목록에서 제목 클릭 시 상세로 이동한다.

## 6. 상태 표시
색상 자체에만 의존하지 않고 텍스트를 함께 표시한다.
- 예정
- 진행중
- 완료
- 취소

## 7. 권한별 UI
- 수정 권한이 없으면 수정 버튼 숨김 또는 비활성화.
- 삭제 권한이 없으면 삭제 버튼 숨김.
- 단, UI 제한은 보조 수단이며 서버에서 반드시 재검증한다.
