# AI Development Team

## Team

- ChatGPT: Project Manager / Architect
- Claude: Primary Developer
- Gemini: QA / Independent Reviewer
- Human: Final Decision Maker

## Rules

1. Read existing code before changing it.
2. Make small and reviewable changes.
3. Do not modify unrelated files.
4. Never commit secrets or API keys.
5. Run tests after code changes.
6. Record important decisions.
7. Update TASKS.md when work status changes.
8. Human has final authority.
